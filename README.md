# Приключения Раллана

Чистый старт проекта детской игры про красную ВАЗ-2114 в Уфе.

## Первый прототип
- Сенсорные кнопки движения и ускорения.
- Знакомый городской пейзаж и стилизованная красная машина.
- Экран обучения с буквами, простым примером по математике и звёздной наградой.
- Автоматическая сборка Android APK через GitHub Actions.

## Получить APK
1. Открой вкладку **Actions**.
2. Выбери **Build Android APK**.
3. Открой последний успешный запуск.
4. Внизу страницы скачай артефакт **RallanAdventure-APK**.

Это начальный прототип, а не финальная версия. Дальше добавим полноценное свободное вождение, задания и адаптивные обучающие мини-игры.
